# Half-Life-Week-5
For week 5 I decided to make several mechanisms that function in a car's chassis to serve as a reference model for a future project I might try. (I would have done a fully mechanical drivetrain but 1 week is too short). 
It features a 6 piston crankshaft, a universal joint that allows for a moving axle, and a differential gearbox to allow the car to move with maximum precision. 
The goal of my project is to test my skills in CAD, 3d printing, and to help educate myself about some of the parts in a car, which I feel like would be important to know as an aspiring mechanical engineer.
